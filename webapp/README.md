# Unlimited OCR Web Application

Веб-приложение для распознавания документов с использованием модели Unlimited-OCR.

## 📋 Требования

- Docker Desktop для Windows
- NVIDIA GPU с поддержкой CUDA (рекомендуется)
- Минимум 16GB RAM
- 50GB свободного места на диске

## 🚀 Быстрый старт

### 1. Сборка и запуск

```bash
# Перейдите в директорию проекта
cd /workspace

# Соберите и запустите контейнер
docker-compose up --build -d
```

### 2. Доступ к приложению

Откройте браузер и перейдите по адресу:
```
http://localhost:8080
```

## 📁 Структура проекта

## 🔧 Конфигурация

| Переменная | Описание | Значение по умолчанию |
|------------|----------|----------------------|
| `NVIDIA_VISIBLE_DEVICES` | GPU устройства | `all` |
| `PYTHONUNBUFFERED` | Логирование Python | `1` |

## 📖 Использование

### 1. Загрузка документов

- Перетащите файлы в область загрузки или кликните для выбора
- Поддерживаемые форматы: **PDF, PNG, JPG, JPEG, WEBP, BMP**
- Можно выбрать несколько файлов одновременно

### 2. Выбор формата вывода

Доступные форматы:
- **TXT** - Простой текст
- **CSV** - Табличный формат
- **JSON** - Структурированные данные
- **HTML** - Веб-страница

### 3. Мониторинг прогресса

- Прогресс-бар показывает статус обработки
- Обновление в реальном времени каждую секунду
- Отображение количества обработанных файлов

### 4. Получение результатов

- Результаты отображаются в виде карточек
- Возможность скачать каждый результат
- Предпросмотр распознанного текста

## 🔌 API Endpoints

### POST /api/upload
Загрузка файлов для обработки

```bash
curl -X POST http://localhost:8080/api/upload \
  -F "files=@document.pdf" \
  -F "format=txt"
```

Ответ:
```json
{
  "job_id": "job_1",
  "message": "Processing 1 file(s)",
  "files": ["document.pdf"]
}
```

### GET /api/progress/<job_id>
Получение прогресса обработки

```bash
curl http://localhost:8080/api/progress/job_1
```

Ответ:
```json
{
  "job_id": "job_1",
  "total": 5,
  "current": 3,
  "status": "processing",
  "progress_percent": 60
}
```

### GET /api/result/<job_id>
Получение результатов

```bash
curl http://localhost:8080/api/result/job_1
```

### GET /api/formats
Получение доступных форматов вывода

```bash
curl http://localhost:8080/api/formats
```

## ⚠️ Важные замечания

1. **GPU требования**: Для работы модели Unlimited-OCR требуется NVIDIA GPU с поддержкой CUDA
2. **Первый запуск**: При первом запуске модель будет загружена (может занять время)
3. **Память**: Рекомендуется минимум 16GB RAM для работы с большими документами
4. **Размер файлов**: Максимальный размер загружаемого файла - 500MB

## 🐛 Решение проблем

### Контейнер не запускается
```bash
# Проверьте логи
docker-compose logs

# Убедитесь, что Docker Desktop работает
# Проверьте наличие NVIDIA GPU
nvidia-smi
```

### Ошибки с GPU
```bash
# Убедитесь, что установлены драйверы NVIDIA
# В Docker Desktop включена поддержка GPU
```

### Медленная обработка
- Увеличьте параметр `--concurrency` в настройках
- Используйте GPU вместо CPU
- Уменьшите DPI для PDF файлов
